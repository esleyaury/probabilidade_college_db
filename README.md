# probabilidade_collage_db
Trabalho de terceira unidade da cadeira de probabilidade da UPE.

[Guia para modelo de relatório](https://github.com/jerfsonbruno/ModeloUPE)

## pré-requesitos para o trabalho

* [Python 3](https://python.org/downloads/)
* [Quarto 1.11.* ou superior](https://quarto.org/docs/get-started/)
* Jupyter
* Virtual Environment para Python(Venv ou Conda)

### Criando o virtual environment e instalando jupyter

(Mac/Linux)
```python 
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install jupyter
```

Windows
```python
py -m venv env
.venv\Scripts\activate.bat // para cmd
.venv\Scripts\Activate.ps1 // para powershell
py -m pip install jupyter
```

Conda
```
conda install jupyter
```

Testar se o quarto está configurado corretamente
```bash
quarto check jupyter
```
